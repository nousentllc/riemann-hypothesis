# Riemann research publication archive

This archive publishes the completed Riemann studies and related editions recovered from the local and Drive-era release inventory. For the experiment branches and current source pins, use the [study catalog](../README.md).

The historical papers and existing ZIPs are retained in their released form. Where a corrected ZIP added a PDF and TeX, both versions are labeled. The interim reader snapshot records a separate stage of that experiment. The archive preserves the reported mathematical and verification scope of each edition.

## Verification

All archive files are individually recorded in [inventory.json](inventory.json) with their SHA-256 hashes. The tests inside the slot-three and changing-cutoff controls refer to the original folder layout. Run the following from this archive with a checkout containing the pinned Git history. The runner recreates that layout in a temporary directory and compares the saved numerical files byte for byte.

```sh
python3 -B verify_archived_controls.py --repo /path/to/riemann-hypothesis
```
