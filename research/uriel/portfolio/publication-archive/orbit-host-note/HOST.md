# Arithmetic hosts for the four finite orbit tests

The prime $3$, its class, and its step all follow from a specified cyclotomic field construction. The computation distinguishes a host satisfying the mathematical type `BasicNotions.Host` from an asymptotically selected host in the RH argument. Every source reference below is to commit `40e56bab026552e089d7afcfeff08d2defb9c005`. The local parameter and set calculations concern the experiment's own explicit finite instances.

The raw finite label of an element agrees with its least nonnegative residue. ## How a chosen prime ideal gives a computable step

Use $J=1,\ \epsilon=1/64$ and $x=2^b$ with $b=32,32,27$, respectively. The scale field restrictions hold. In all rows $3<X'=\exp(2^{b/192})<4$. For a rational check, $\exp(11/10)>3$ already in the fifth Taylor partial sum, $(11/10)^{64}<2^9$, and $2^{1/6}<6/5<\log4$ . The inequality $\log 2>2/3$ follows by integrating the strictly convex function $1/x$ on $[1,2]$. Hence the prime range before filtering consists of $2,3$. The prime 2 divides $Q_S$ and has the ramified class. The prime 3 is coprime to $Q_S qd$. It is in the inert class since $(-d/3)=-1$ and `psAt 3` equals $(3/q)=-1$. [Class definition, lines 33–37](https://github.com/nousentllc/riemann-hypothesis/blob/40e56bab026552e089d7afcfeff08d2defb9c005/src/Formalism/LocalRingCardinality/DataHost.lean#L33) · [Artin sign and PsQ, lines 68–83](https://github.com/nousentllc/riemann-hypothesis/blob/40e56bab026552e089d7afcfeff08d2defb9c005/src/Formalism/SharpRestriction/RamificationFrobenius/TotientGaloisClasses/ConjEMemHostFIff.lean#L68)

The classically selected group element in `hPH H 3` has a unique value. A prime ideal above 3 exists by lying over; the host's Frobenius field supplies an arithmetic Frobenius there. For every such ideal and lift, its Galois class equals the Artin image of the unit $3\bmod Q_S qd$. The defining projection law sends the $A$-part of this image to the class of $3$ modulo sign in $(\mathbb Z/Q_S)^\times$. Bijectivity of the projection on the cyclic frame makes its coordinate unique. The half- and full-order powers in this table also certify that its additive order in $A$ is $n$. Thus the order filter $x^{\epsilon/4}=2^{b/256}<2\le n$ passes. The final prime support in each test is exactly ${3}$, and the inert step is `hPH H 3`. ## Boundary of the inference

Here `RankVal` would require $n\ge x^{2+8\epsilon}=2^{17 b/8}$; this is false in each of the three rows above. The promoted `Host` uses split bound zero, whereas `HostVal` imposes a positive scale-dependent lower bound. In the three index-one controls, there is no nontrivial quotient character because $A_0=A$. These experiments settle the sufficiency question for the weighted condition on the domain of typed arithmetic hosts: cardinalities in the quotient alone can agree while `BadOK` changes. They cannot decide whether matching host pairs survive `RankVal`, `HostVal`, or the asymptotic family construction. The typed host existence involves a genuine choice of auxiliary number-field witnesses; the prime class, the step, and all retained-set predicates reported here are fixed by the supplied integer data. ## A nontrivial quotient at layer 64

Choose the same cyclic group of order $n=2^{64}$, but take the distinguished generator to be $2$ instead of $1$. Then $A_0$ consists of even residues, so $n_0=2^{63}$ and the quotient has order two. The projection used in the cyclotomic host construction remains bijective for this generator choice. The host's restriction $o^{64}\le2^e$ holds at equality. Thus a power-of-two frame with a two-coset quotient cannot be smaller than this if it meets that source restriction. [Frame with a power generator and index, lines 152–176](https://github.com/nousentllc/riemann-hypothesis/blob/40e56bab026552e089d7afcfeff08d2defb9c005/src/Formalism/SharpRestriction/RamificationFrobenius/TotientGaloisClasses/FrameCyclicGenerator.lean#L152)

Use $k=2n,\ m=2,\ t=k+7$ as before, $x=2^{27}$, $\epsilon=1/64$, and $J=1$. The rank inequality for the two primes is $q,d>5{,}444{,}517{,}870{,}735{,}015{,}416{,}594{,}585{,}339{,}625{,}702{,}686{,}749$. The primes are
```text
q = 236789744721782169152365302750626042756803 = 2 × 89 × 3^82 + 1
d = 135688505402369557604164386969459867197719 = 2 × 17 × 3^83 + 1
```
Here $q\equiv19\pmod{24}$, $d\equiv7\pmod{48}$, and $(-d/q)=1$. Lucas certificates use base 2 for $q$ and base 3 for $d$. With the factorizations displayed above, those bases have order $q-1$ and $d-1$, respectively. These are full-order certificates in the Lean supplement. The independent census uses a shorter certificate based on the power $3^{82}$. As before the prime support is $\{3\}$. At $Q_S=2^{66}$, the raw step $v=11487458370492081827$ satisfies $5^v\equiv-3\pmod{2^{66}}$. Its inverse modulo $2^{64}$ is $2556611305511861515$. The power $3^{n/2}$ reduces to $2^{65}+1$, and $3^n$ reduces to $1$. The odd step preserves parity between raw labels and orbit positions, so the quotient's cosets are exactly the even and odd positions in the experiment. The integer comparisons $3^{1935}<2^{3068}<3^{1936}$ certify $L_2=3872$. In this arm both sets have the exact prescribed parity counts $5270498306774153980$ and $3952873730080615485$, in ratio $4:3$.

The first three frames are smaller than the lower bound in the source’s `RankVal` size window. The fourth frame exceeds its upper bound because $2^{64}>2x^{2+8\epsilon}=2^{58.375}$. The four cases therefore concern the host predicate at explicitly specified scales. Whether the same perturbation can be made on the asymptotically selected hosts remains open.

## Reproduce the Lean results

`ConcreteOrbitHost.lean` builds four typed existence statements and a general lemma `Uriel.OrbitHost.chosen_step_eq_artin`. It verifies the two primes, the Jacobi-symbol condition, the remaining numerical rank fields, and the host constructor premises inside Lean for each pair. The prime certificates use the formal Lucas criterion and modular exponentiation by repeated squaring. The Frobenius lemma instantiates lying over, the source's unramified Frobenius theorem for these hosts, and uniqueness of its Artin image to evaluate the original epsilon choice. The weighted sums, integer sequences of retained positions, and compound `BadOK` truth values are checked separately in the finite experiment. This module alone does not assert those computed outcomes.

First reproduce the [public retained-host source and library audit](https://github.com/nousentllc/riemann-hypothesis/blob/9ac7e1b546b132edde02709e1c0af1bfccd40755/research/uriel/experiments/retained-host/REPRODUCE.md). Use the checkout at that public experiment revision, the extracted original source tree at the published pin, the matching Lean and Mathlib installations, and the audit's resulting library in the following command. `PUBLIC_REPLAY_RECORD` denotes the public verifier's JSON output on your machine.

```sh
python3 -B replay_host.py --checkout "$CHECKOUT" --original "$ORIGINAL" \
  --toolchain "$LEAN_ROOT" --mathlib "$MATHLIB" --library "$REPLAY_WORK/lib" \
  --manifest "$PUBLIC_REPLAY_RECORD"
```

The verifier compares all original source blobs with the pinned Git tree and verifies the digest of the 1,205-entry source and object inventory against the public experiment record. It then builds the supplement in a fresh directory and runs the separate kernel replay command `leanchecker -v ConcreteOrbitHost`. The recorded output reports only `propext`, `Classical.choice`, and `Quot.sound` for all five printed endpoints. The public record provides the cache trust boundary for previously built original modules and the pinned Mathlib environment. Byte-for-byte comparison with the supplied verification JSON applies to a matching toolchain and object inventory. Other platforms may yield different object digests after the public verifier rebuilds the original sources.
