# Scalar extension from an independently certified endpoint

Recorded before new runs on this channel. The modulo-four peak and bounds in studies 16 and 17 are known. We test whether a fixed-family scalar comparison can cross the boundary of an original selected window without producing an additional local host.

1. Prove a global Lipschitz bound on the smoothed fixed positive character-family sum from periodicity, nonvanishing at 1, and the elementary Chebyshev bound. Isolate the linear normalization on each side of the finite divisor convolution. For conductor four test a concrete safe constant K=2. For integers N<1024 enclose all right-hand piecewise slopes independently with directed arithmetic; for all N>=1024 use an analytic Chebyshev inequality and alternating remainders. Record the exact finite test for the junction. The number 2 is a candidate upper bound, not an optimality claim.
2. Independently certify the finite signed divisor convolution at N=16,64,257,511,1024,4096 using arithmetic on rational coefficients of log primes, with no interval tolerance. Include a missing prime-power and omitted linear correction control. Check the binomial step for the Chebyshev bound on both parity classes, including the middle term in the odd case.
3. Using the previous cofinal pointwise source bound at a stronger exponent sigma<theta, derive one-ended exterior neighborhoods of additive width proportional to t^theta. Test conservatively rounded exterior radii at known ordinates 256, 487, 512 and 4096 on the true chi4 signal with a preregistered local ceiling c*sqrt(y), c=3/20. Certify the fresh interior/range values by evaluating all knots, and compare the global guaranteed radius with the local measured slack. Do not identify these points with selected hosts. Include a continuous adverse signal sharp for the Lipschitz-only interface, and an additive-versus-relative-width control on a growing geometric gap.
4. Derive a position-sensitive two-ended spacing estimate using the earlier ramp interpolation theorem. Quantify when endpoints alone imply sufficient full-window mass. Distinguish source-certified data, inferred scalar values, and scalable hypotheses not supplied by the pinned arithmetic.
