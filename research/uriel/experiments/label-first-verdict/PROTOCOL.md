# When both survivors are already visible, does labeling them first prevent a mistaken conclusion?

Prospective paired experiment, November 24, 2026. The predecessor's filtered reader delivered 23 verdicts with exact survivors and misread the labels on three. Those three responses motivate this question and are excluded from the test sample. We compare the original two-row direct-answer prompt with a compulsory, externally observable first answer giving the Y/N label for each row. No retraining and zero direct API charges.

## Records, order and administration

Six newly generated physical layouts differ in vertex/edge counts from all 26 earlier layouts and each other. Four records per layout show YY, NN, YN and NY once each in printed order. The two mixed records have disjoint survivor IDs; the decisive replies require opposite verdicts. Each marginal lamp reading admits both truth values. No hidden switch setting is designated. Exact rational currents determine row signs via strict greater-than. Show exactly the two surviving rows in both arms, with the original signs visible in the last column. Use the same public evidence, system prompt, method, model digest, and final verdict schema. Call order is balanced within sign pattern and between waves using the registered seed. Each record is seen by each arm once in a fresh context. No resampling or answer edits.

Direct asks for the verdict and witness IDs in one call. Label-first initially requests only a Y/N value keyed to each of the two survivor IDs. The grammar supplies both keys, and neither value is prefilled. Only a valid explicit pair of Y/N labels unlocks a second call. Pass the model's own visible JSON verbatim as the assistant message, then request the verdict and certificate. Supply no correctness feedback. The second call sees the same original evidence, so it may correct or contradict its earlier labels. The final schema in both arms allows every one of the eight IDs. The checkpoint compels public output order; it cannot constrain when a private conclusion is formed. Extra inference, context and decoding budget are part of the treatment.

Same local Ollama 0.40.18, gpt-oss:20b digest and low reasoning as predecessor. Temperature zero, 8192 context, 2048 generated tokens per call, 900-second timeout. Final-call seeds paired by record; first-stage labels use a fixed offset. Maximum 72 calls. Archive terminal text, request bytes reconstructed as canonical JSON, timing and tokens. All contingent verdict requests are frozen templates with exactly one data slot, bound at dispatch to the preceding visible response. A missing label answer gates off that verdict and the workflow counts as a failure. A length limit or transport error is recorded separately from a delivered but wrong verdict. No duplicate requests after interruptions.

## Endpoints and scope of inference

Primary: delivered warranted final verdict on each of the 24 records, by workflow, including missing as failure. Report the paired count difference and both off-diagonals, and one exact two-sided sign-flip reference using the six layout-level score differences (all 64 flips, absolute sum, fair independent signs reference). Layouts are purposively constructed; four records per layout are correlated. This is a fixed-panel contrast. Report exact witnesses plus warranted verdict as a common secondary endpoint, and all-four-verdict-correct layouts. Report primary scores by ordered sign pattern and committed-label accuracy by ID, by pair, and by final verdict. Identify each response with both accurate labels and a contradicted final verdict, with ID and counterexample. Report whether each verdict follows from the reported labels, even if those labels were inaccurate. A wrong final verdict and a missing final answer are distinct. Report attainable primary bounds over binary completions of missing workflows. No proof of equivalence or general improvement from a tie. No Lean replay or conclusion about RH.

H1. If externalizing both signs prevents the observed errors, label-first should exceed direct on delivered warranted verdicts, with few or no wrong verdicts after an accurate commitment. H2. If combining already-correct signs remains fragile, at least one valid verdict can disagree with two accurate committed labels; a single such trace refutes perfect prevention on this panel. H3. If labeling introduces a new failure, some incorrect labels may propagate, be corrected, or use up the available generation budget. Explicitly enumerate these cases. If direct makes no verdict errors, the panel cannot demonstrate correction of direct errors. An ideal public algorithm checks unanimity and is perfect in both arms. A first-row-only verdict is always definitive and fails on every mixed pair. These checks establish what can be computed from the printed facts, independently of the language model.
