# Supplemental analysis of reported labels

Specified during collection, before reviewing any model outcomes. For each label-first call, take the model's own submitted pair and apply the deterministic unanimity rule. A missing report stays missing. Compare this offline verdict with the warranted one and with the actually issued verdict. Publish counts of cases where both succeed, only replay succeeds, only the model succeeds, or neither succeeds, together with the per-case IDs. This indicates how much of the available upstream information could be preserved by a deterministic final step. It is an evaluation of a rule on fixed, already-collected label reports, not a third administered model arm. It makes no claim that the same reporting behavior would emerge in another interface. The independent checker exhausts all 48 possible binary truth-pair, reported-pair and model-verdict combinations.
