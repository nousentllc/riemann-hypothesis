# Finite controls for the descent and cancellation argument

Use finite abelian groups with prescribed cyclic factors, some nontrivial of order prime to 7, some with 7-torsion. Enumerate seventh powers and compare the quotient size to the formula using gcds. In cyclic Z/(7^2), test the cokernel of u^(j*7^m)-1 with u=8 or 2, signed weights ±1, ±6, ±7, and m=0,1,2. Compare its exact order to exhaustive image enumeration. Include the zero module for every combination. Unit 8 reduces to one modulo seven; unit 2 is a distinct algebraic control. These are finite linear/abelian substitutes for the rank and quotient operations, never the actual cohomology group or a realization of an arithmetic tower. Test whether a zero-dimensional domain can ever give a positive cokernel and whether a positive-dimensional input that passes one count guarantees all pass. For R,R'=0 and c=0 verify that ℓ^c=1 and the original bound coefficient is zero at every (m,B) in a finite panel. Prove the unrestricted version symbolically inside Lean.
