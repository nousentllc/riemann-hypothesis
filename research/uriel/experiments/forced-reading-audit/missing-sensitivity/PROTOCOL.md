# Sensitivity to missing or invalid completions

This supplemental analysis was specified after a transport timeout was reported during inference, before inspecting model decisions or releasing scores. It leaves the registered missing-as-zero analysis as the reported result. Its question concerns identification: if every visible, accepted answer is held fixed, what values would the three development criteria permit under any admissible replacement of the unobserved decisions?

Keep each parseable, accepted session's exact-ID and joint-certificate indicators fixed. For each missing, truncated or otherwise unaccepted session, allow all three logically possible pairs (exact IDs, fully certified): (0,0), (1,0), (1,1). The response schema can realize all three on every case. These are equivalence classes for these endpoints, not probabilities. In particular, an answer with a warranted sign and an invalid ID set belongs to the first class. The endpoint geometry is the same for the ambiguity controls because exactly two opposing survivors appear in every control.

Enumerate the possible six-session configurations of each layout. Build its attainable triples of filtered-minus-full differences: complete decisive family, number of decisive records with exact IDs, and number of certified ambiguous controls. Convolve those triples across layouts, retaining multiplicities of equivalent completions. Evaluate the original threshold on each *jointly attainable* triple: first difference at least two, second difference at least two, third difference nonnegative. Report the sharp marginal ranges, the observed zero-credit values, which gate outcomes can occur, and missing counts by arm (also by recorded status). Do not average possible replacements or estimate a missing-response distribution. A separate monotonic-extremes calculation should reach each endpoint bound and give the same conclusion on gate sensitivity. Check tiny synthetic cases by ungrouped exhaustive enumeration, including scenarios in which the recorded decision is immune and scenarios in which it can change. Test the all-missing limit at six layouts. Do not access real observed responses before explicit outcome release.
