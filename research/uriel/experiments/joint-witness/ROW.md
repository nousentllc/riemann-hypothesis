# The prime pair, field and family index

Fix a primitive character $ψ$, an admissible $ε$, and one sufficiently late scale on a window supplied for this character. The proof lets us name one host in such a derivation. The final record does not specify a canonical pair at that scale or retain the original exception lists.

## Obtaining a row with its own window

1. **Select the pair.** A positive-cardinality argument obtains $q$ in a first good set, then $d$ in a second set depending on $q$. The resulting `PairGood` includes coprimality to the character conductor, estimates for twists throughout an interval, and zero-free boxes for certain induced real twists. `PairRow` requires primality, congruences, size intervals, splitting symbols and a conductor bound. The analytic conditions have additional content beyond those arithmetic tests. 2. **Use those primes to choose the cohomological window.** After selecting the page function $e$ and $J,X_0$, the proof chooses a sufficiently large $X$, sets $Y=X^{1/J}$, obtains $q,d$ there, and applies the window theorem to that exact pair. It obtains $W$ with $Y≤W$ and $W^2≤X$. Put $k=c^{1/(2+8ε)}$. Over $kW≤x≤(kW)^{3/2}$, it exhibits the same $Y,q,d$ with page $e(x/k)$. ## A field and a row in one host

4. **Choose the field and ranks jointly.** The field theorem takes $e,q,d$ and the splitting cutoff. It returns a frame, a host field, exact prime identities and frame order $c2^e$. Admission supplies ranks on that frame satisfying `RankVal`. The proof uses the same $H_0$, page and pair to build an enriched $H$ with `H.toHostAx = H₀`. Field construction here also needs $q≠3$. The proof obtains it at sufficiently large scale. This is an immediate failed prerequisite for the finite $q=3$ trial. The character-specific construction permits a frame-order factor $c$ that the cyclic frame in the earlier scalar experiments set to one. [Field and prescribed pair](https://github.com/nousentllc/riemann-hypothesis/blob/40e56bab026552e089d7afcfeff08d2defb9c005/src/Development/AutomorphicArithmetic/CharacterBoxes/FieldChi.lean#L20-L28) · [Field, rank and host equalities](https://github.com/nousentllc/riemann-hypothesis/blob/40e56bab026552e089d7afcfeff08d2defb9c005/src/Development/AutomorphicArithmetic/ShortNorms/supplyOfAdmOf.lean#L91-L116)
5. **Locate the actual row.** Within the field-to-host construction, auxiliary primes and an integer set $T$ are chosen, then installed in a host $D$. `pairRows` yields `hrow : PairRow Y ε D`. The same triple $⟨Y,hW,hrow⟩$ goes to the top-place selection and into the returned `HostVal`. The host update installs the selected $TT$ and preserves the pair and field. A further use of the triple packages the box condition. The chosen $TT$ and integer thick set $T$ have different types and purposes from the cohomological exceptional sets. ## Passing from a host to a family

7. **Preserve identities through point choices.** At a fixed admissible scale `kitS` takes one host, then chooses a point for each integer $u_0<R.n$ using that host. `Pt.From` records equality of ranks, $q,d$, $T_2$, and the images of $TT$, plus heterogeneous equality of the underlying host structures. `FReq.at_of_from` uses rank substitution, this host equality and injectivity of the digit map to transfer the host condition to each point. `famOfKits` uses these points for its data and explicitly records equality of primes across indices at fixed $x$. 8. **Fix the final index.** The design theorem selects one family and invokes both its cohomological bound and the links on that family. Inside `ChainTied` one distinguished $i_0$ determines the frame, prime pair and arithmetic data, while $pt(u_0)$ supplies point-specific words. `TiePts` identifies each such point's primes with those of $i_0$. ## A stronger quantifier order inside the original argument

On reading the registered route we noticed a stronger conclusion and tested it as a follow-up. The published conclusion lets the witnesses $Y,q,d$ vary at every $x$. Assume $0<ε<1/52$, $c≥1$, `VWinAt ψ 401` and `PairEx`, as in the published result. The strengthened conclusion is

$$
\exists J\ge1,\quad \forall y,\quad \exists Z,Y,q,d,\quad y\le Z\ \land\
\forall x\in[Z,Z^{3/2}],\quad \exists e,\ \mathrm{WinDatum}(ψ,ε,J,c,x,Y,q,d,e).
$$

The proof body has 73 lines. Two lines move the three witnesses outside the binder for $x$. All 71 other proof-body lines agree with the pinned original. This retains a common pair per selected window. Another window may use another pair, and a page may change inside a window. The new weakening lemma has Lean's exact inferred type of the published theorem. The two-row control uses the same real power windows and a different predicate: one row accepts rational inputs, the other irrational inputs. Every point has a row. Every such window with $Z>1$ contains both a rational and an irrational point, so neither row covers it. This shows precisely why the stronger result needs a property of the source proof. [Original witness choices](https://github.com/nousentllc/riemann-hypothesis/blob/40e56bab026552e089d7afcfeff08d2defb9c005/src/Development/AutomorphicArithmetic/CharacterBoxes/WinPairs.lean#L34-L35) · [Original placement of binders](https://github.com/nousentllc/riemann-hypothesis/blob/40e56bab026552e089d7afcfeff08d2defb9c005/src/Development/AutomorphicArithmetic/CharacterBoxes/WinPairs.lean#L52-L65)
