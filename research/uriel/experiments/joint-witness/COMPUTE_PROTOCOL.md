# Finite probe registration

This protocol precedes execution. The trial translates the prime row's numerical clauses and the cohomological selector into one set of shared coordinates. A numerical instance of `Rowq` has fewer inputs than a `Host`. Exception labels and their budgets are supplied test data. The experiment measures where extension to the original existence argument stops.

Fix ε=1/64, Cₜ=401, Cₖ=1, R₀=1 and one odd component of budget 1. Let η=ε/(2Cₖ), B=Cₜ/η, R=2, J=2^(R+2) B^R. Use the common outer scale X=2^U with U=48J. The pair scale W=X^(1/J) is exactly 2^48. Use base-two log coordinates and represent enormous exact powers by integer exponents.

1. Choose q=3 and F=2^1279−1. Verify F by Lucas–Lehmer with prime exponent. Search in increasing k=5 mod 24, 5≤k≤200000 for d=2kF+1. Require a Pocklington certificate with known factor F>√d and a witness 2≤a≤100. Report the first certified d, k, witness and all clause decisions, including any vacuous small-prime range. A bounded unsuccessful search is an experimental failure. Test the congruence, Kronecker symbol, strict lower/non-strict upper boxes and log bound using exact integer comparisons or enclosing rational bounds. Report each prime-bit count.
2. Set the two exception labels to powers of two with logarithms CₜU/2 and CₜU/(4B), respectively. Feed their union to the source recursion. Check the output on the whole closed interval via an independent forbidden-interval oracle. Removing the odd component should admit a window that fails for the omitted label. Record a counterexample coordinate.
3. Use the midpoint in log coordinates of the resulting window for x. Compute e=ceil((2+8ε)log₂ x), n=2^e, Qₛ=4n and t(x)=floor(x^401). If t is a power of two, record its exponent. Reuse exactly W,q,d,Qₛ across the row computations. Check the pair-window relation W≤x≤W^J, the PageN bound, and the weaker cohomological PrimePair at conductor 1. Changing q to 11 should preserve these elementary primality and congruence checks but fail the q box. Test whether the *same* row passes the cohomological log-size condition log(qd)≤X^(ε/(4J)) and the later large-prime cutoff q,d>2X^401+1. Predict failures at this finite scale. Record failure to satisfy any further named prerequisite as a failed condition, while the unevaluated existential thresholds and actual field data remain unknown.
4. No actual two-primary or odd-prime cohomology output, class-group computation, size threshold, host, or `CoreAtH` follows from supplying these labels. A second implementation must check certificate mutations, boundary equality in the selector, retained union membership, row scale and the limiting-condition results.
