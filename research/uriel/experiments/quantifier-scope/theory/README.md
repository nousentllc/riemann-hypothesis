# What observations distinguish two binary questions?

Each record produces two binary answers in the order (at least one, both). A stable deterministic mapping that uses only the two true labels has four possible signatures on each of four ordered input patterns. There are exactly 256 such mappings. The mixed inputs carry all of the distinction between the intended mapping and using OR for both questions. An answer strategy that always emits Y to the first wording and N to the second can also pass every mixed pair. It fails both unanimous control classes. A stable always-yes answer can pass mixed OR/OR checks but disagrees with OR on the two-negative inputs.

The design-only verifier enumerates the finite class of mappings, its named competitors and their predictions, and the smallest sets of ordered input patterns that distinguish the intended table from all named alternatives. This is identifiability of input/output tables over a two-bit domain. The same table can result from different private algorithms. Homogeneous tables allow detection of response bias; order-reversed mixed inputs make row-copying policies observable.

The supplemental scoring applies each named mapping to the **physical** row labels and compares it with the observed pair. A match requires two returned answers and the exact predicted signature. An observed incompatible bit rules out a match even when its sibling is missing. If neither observed answer contradicts the policy but one or both are missing, the record could match. Missing outcomes affect the optimistic bound only. Compare the intended and doubled-OR policies on mixed records with all records retained, and again on the subset with accurate labels and both children delivered. Report all complete-input truth tables with the best joint count and the best count of any single deterministic mapping, labeling the latter as a descriptive fitted ceiling. The word-only strategy and other candidate policies use no new model calls.

A secondary cluster-preserving directional reference compares supported joint signatures (Y,N) versus (Y,Y) on the mixed cases. Each layout contributes its separated minus doubled-affirmative count. Enumerate all 64 fair sign reversals of these six layout differences and report the two-sided probability of an absolute sum at least as large as observed. Other signatures and incomplete cases score neither. The conditional symmetry reference describes this panel and its stipulated null. The records do not form a population sample, and frequencies of the seven selected historical errors are not pooled with the new panel.
