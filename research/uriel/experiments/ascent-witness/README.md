## A proof for every layer

Write $h(F)$ for the number of ideal classes of a number field $F$. For every $n\ge1$, Lean proves $3\nmid h(\mathbf Q(\zeta_{3^n}))$. It uses the actual inclusions between the source fields. The conclusion permits class numbers larger than one. The independent finite calculations give class number one in the first three layers. This specialized result has a classical antecedent in the class-number theory of cyclic prime-power extensions. The contribution here is the checked connection to this formalization and its chosen field model. [Checked induction and transport](TowerResult.lean) · [Classical background and exact class norm](ASCENT.md) · [Finite field computations](FIELDS.md)

1. The bottom field has class number one. Each successive extension is cyclic of degree three. Exactly one prime of the lower field ramifies, and it has ramification index three. [Bottom field](../slot-three/BaseField.lean) · [Actual layer inclusions](LAYERS.md)
2. Suppose three divided the upstairs class number. The Hilbert class field then supplies a nontrivial unramified extension upstairs whose automorphism group has exponent three. Its construction from cubes is preserved by the symmetries of the tower. The proof checks that it is Galois over the lower field as well. [Construction](UPSTAIRS.md) · [Hilbert field preserved under conjugation](HilbertNormal.lean)
3. The resulting group over the lower field has order a power of three and order greater than three. Its only potentially nontrivial inertia subgroups have order three and are conjugate. A normal subgroup of index three contains them all. Its fixed field is therefore an everywhere-unramified cyclic cubic extension downstairs. By class field theory, its degree must divide the lower class number. This contradicts the induction hypothesis. [Inertia descent](InertiaDescent.lean) · [Group and class-field steps](ClassAscent.lean)
4. Applying this induction removes the earlier premise from the vanishing of the layer invariant, the two opposite answers using one lift, and the estimate for a named center. Independently, the class norm identifies upstairs classes modulo conjugation differences with downstairs ideal classes. The number of fixed upstairs classes equals the downstairs class number. [Transfer identities](Transfer.lean) · [Joined endpoints and precise hypotheses](TowerResult.lean)

An independent control changed the set of ramified primes and kept the same bottom field. Two cyclic cubic extensions then had class numbers 36 and 9, with nine fixed classes in each. In the original tower the fixed-class count in the first step is one. This experiment supplies explicit counterexamples to extending that count indiscriminately. ## What can be recovered about the witness?

One generator and one surjective presentation can be chosen before the cutoff or the label is specified. Every choice below uses that same zero matrix and presentation. The designated center can vary with the label. Fixing one center across cutoffs imposes its own consistency on the answers. [Quantifier order in the shared-lift theorem](SharedLift.lean)

For a cutoff $Z$, a designated integer center $a$ between zero and $Z$ gives the empty set if $a=0$ and the singleton $\{a\}$ otherwise. Every one of these choices satisfies the cap-one bound. Conversely every cap-one filter from a 3-adic center agrees with exactly one of these $Z+1$ membership profiles. Lean proves both a matching upper bound and a lower bound on the number of possible record values when a reader must answer every later membership query. At cutoff 64 the answer is 65, or seven fixed-length bits. A single question fixed in advance only needs its answer bit. The published compactness argument and the later uses of classical choice provide suitable witnesses without recording their residues. Proving that both answers are admissible does not identify the value of that choice. The other prime slots and the final common host also involve further data.
