# Registered finite branch tests

The unit is one served even-length inert orbit at a specified lift, with the same prime, mask, integer heights, offsets, constants and first-hit exclusions supplied to all expressions. The outputs are the unshifted demand, shifted demand, both proposed gains, zero, the selected maximum and the odd-row charge. We will also report the unserved branch for the same numeric orbit. A finite cycle is a control for the local formulas. The arithmetic assertions that certify good and served are outside this experiment.

**Primary panel.** Use the cycle of length eight, base zero, step one, prime 5, lift 1, lift parameters 8 and 3, giving shift 6. Set the scale height to 3125/2, the integer top height to 1563, the integer top level and its reference value to 150, the lower top offset to 64, every nontop offset to 8, offset spread parameter 1, curvature 2 and numeric auxiliary rank 1. The common subtraction uses coefficients 1/64, 1/64 and the high-range penalty coefficient is 1/16. Thus log base 5 of twice the scale height equals 5 without numerical approximation. Treat the high-prime case as the explicit conditional side of the local definition. Enumerate all 255 nonempty masks.

* H1. The even-only singleton at 0 favors the universal branch. The odd-only singleton at 3 favors the direct branch. An artificially increased common subtraction makes zero strictly win for both singletons.
* H2. A full pointwise odd charge can accompany either branch. Predict that masks {0,3} and {3,4}, both with one unpaired odd position, give opposite winners, the direct branch first. For the adjacent mask {0,1}, the intervening even predecessor should clip its odd charge fully. Check the nonnegative unused geometric tail separately before reporting saturation.
* H3. The common subtraction shifts both nonzero candidate gains by exactly the same amount. Changing it alone cannot switch their ordering. Changing the high-range penalty should move the universal branch only. Include a high penalty, an exact positive tie set by solving for that penalty when possible, and a case in which zero strictly wins. The exact tie is a constructed boundary control.
* H4. The direct branch excludes only the first odd arrival at a distinct top. The two infinite series should agree with a finite-prefix-plus-tail computation using a different summation order. Include a stress control where a return to the same target on a later lap is positive, to detect accidental exclusion of all laps.
* H5. For sparse masks on a growing cycle the full unpaired odd-row term can tend to its nominal allowance, while the actual gain is still selected by a separate maximum. Test the masks {0,3} and {3,4} at lengths 8, 16 and 32 with the following growing-bulk panel. Take prime P from 5, 101, 1009. Use a= P³/2, integer height ceil(a), b=floor(a/(2P)), lambda=b/4, thin=lambda/n, shift zero, curvature zero and both subtraction and fixed penalty coefficients zero. These zero parameters isolate the branch mechanism and its scaling. They are an ablation of the family premises.

The main counts use exact rational comparisons including ties. A strict win means a uniquely maximal one of U, G0 and zero. The signed gap may be negative. The high-prime penalties retained in the primary panel need not be the ones on any global witness. The experiment does not estimate a branch frequency in the selected family.
