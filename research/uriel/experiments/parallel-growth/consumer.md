# What the rank-one normalization actually consumes

Fix a nonzero scalar target β, write D = [F:Q] and M for the Hermitian source dimension, and let P(a) be the real product over finite places of the scalar-fiber measures of the lattices dilated by the positive integer a. Let w be the extended nonnegative integral of the archimedean test function against the archimedean fiber measure. Its real value is strictly positive on the nonzero branch. All these objects and the Euler multiplier c refer to one fixed choice of input data.

## The exact criterion

For a set S of allowed positive integers and a nonnegative profile P, consider the scalar comparison

    |c − 1| w P(a) ≤ C a^q       (a in S).

Here w > 0 and C is a finite real constant. This comparison forces c = 1 for **every** multiplier and finite error constant if and only if P(a)/a^q is unbounded above on S. In Lean the statement uses B a^q < P(a) for each B, which avoids dividing on a zero input. This is an exact characterization of the scalar argument. It does not characterize all possible geometric proofs that a multiplier equals one. [Lean criterion](verification/GrowthConsumer.lean)

If c differs from one, division gives P(a)/a^q ≤ C/(|c−1|w) throughout S. Conversely if P(a)/a^q ≤ B, choose c = 2 and C = wB. They satisfy the inequality throughout S. A power gap is one way to prove unboundedness. A profile of a^q times a slowly growing unbounded factor meets the same criterion. Neither the explicit value of the density at one fixed place nor the spacing of S appears here. The progression theorem gives extra arithmetic information about **which** dilations satisfy a lower bound.

The source supplies a constant κ > 0 and arbitrarily large integers a for which κ a^p ≤ P(a). The discrepancy bound is available for **every** positive integer, so the proof may apply it at those very a. In the original p = D(2M−2) and q = DM. Their difference is D(M−2). The comparison proof needs only one degree of positive gap in these integer exponents. With M ≥ 3 and D positive, the proof gets it. The theta estimate supplies an observed integral I and an error bound |I−wP(a)| ≤ C a^q. The Euler identity identifies that same I with cwP(a). An unrelated product would give no bound on |c−1|.

## Two controls checked in Lean

* At the boundary p = q, and more generally for p ≤ q, set P(a) = a^p and c = 2, w = κ = C = 1. Both bounds hold at every positive integer. Thus the conclusion c = 1 cannot be extracted from those two power bounds alone. The counterexample concerns the two scalar bounds. Whether another argument can determine the actual rank-two measure is a separate question.
* Let P(a) = a on even integers and zero on odd integers. With c = 2, a linear lower bound holds on arbitrarily large even integers, and the absolute discrepancy is bounded by one on arbitrarily large odd integers. Both witness sets are cofinal. There need not be even one matched witness large enough to contradict c = 2. Their intersection is the issue.
