# Exact sensitivity of the sealed panel to changes of arithmetic rule

This investigator diagnostic was specified after registration of the circuit comparison and before its model outcomes were examined. It uses only the sealed designs and records. Its purpose is to test whether the selected fixtures can reveal specific arithmetic failures. It provides no inference about arithmetic actually used by any model.

For physical current I and signed threshold t, compare four alternative candidate truth assignments with the registered I > t. The first uses I ≥ t. The second uses |I| > t while preserving the signed threshold. The third uses |I| > |t|, which is a different interpretation of magnitude. The fourth rounds I and t, separately, to the nearest tenth of an ampere with ties to even, then compares the rounded values strictly. Use exact rational arithmetic throughout. Every public lamp and each initially eligible set stays fixed. Run all four alternatives on all 48 distinct settings of the six fresh layouts.

For each originally actionable record, recompute the truth classes among its four eligible states, all possible lamp replies and the optimal one-measurement verdict on the designated physical outcome. Record which menu items decide for every reply whenever the initial class is mixed. Record a status change to already settled separately from a lost or substituted decisive meter. If resolution is possible only on the actual reply, label it contingent. Under each altered rule, count how many of the six actionable records retain the original guaranteed-meter set and how often one acquires a different guaranteed meter. List records where the originally guaranteed meter can no longer settle a mixed target.

For each of the other six controls, enumerate the complete family of certificates allowed by the original verdict at the initial observation. A determinate certificate contains all four compatible IDs. An ambiguous certificate consists of any unordered pair with opposing signs. For each altered rule, mark how many original verdict-and-ID certificates remain valid. A pair keeps an ambiguous certificate even if both of its truth values flip. Distinguish controls that lose some certificates from controls that lose every certificate. Separately report changes to the strongest attainable outcome on those controls. Archive all changed state labels, meter partitions, actual attainable outcomes and individual initial certificates for inspection. The original comparator is a positive reproduction control.
