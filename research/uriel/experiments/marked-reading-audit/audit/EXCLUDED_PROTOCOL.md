# Supplement on submitted witnesses

This descriptive analysis was specified during collection and before inspecting any response content. The published primary endpoint, scoring rule and denominators stay fixed. The collector runs independently; the analysis opens response contents only after all 72 terminal receipts exist and the complete case table has been scored.

**Which observation rules out a cited setting?** On each response, classify every occurrence of an excluded ID into one exclusive category. “Initial only” means the setting matches the initial lamp and fails the second. “Second only” means it matches the second lamp and fails the initial one. “Neither” means it fails both. A jointly compatible ID is outside these three categories. Give counts by ID occurrence, including repeated IDs, and by response containing at least one ID in that category. One response may enter several response-level categories. The sum of the occurrence counts must equal the number of excluded occurrences. Report the total number of attempted and completed responses alongside these counts.

**What differs when exactly one of marked and filtered succeeds?** For each record with a unilateral certification, identify the successful display and inspect the other display's visible verdict and submitted IDs. Report exact-set success including the no-duplicates rule, verdict success, omitted and extra settings, duplicate count, and whether the verdict follows from the labels of its own nonempty submitted set. The resulting categories are complete certification, witness defect only, verdict defect only, both defects, or no completed answer. A transport or format failure receives a separate category, and its empty output is not treated as an observed decision about which settings to omit. Label coherence describes the public answer. It makes no claim about what calculation occurred privately.

**Which evidence contradicts a definitive answer on a mixed pair?** Each mixed record has one compatible setting of each polarity. For each unsupported definitive claim, publish the ID supporting the returned sign and the compatible opposite-label ID that refutes it. State whether either was cited, whether the returned verdict follows from the submitted IDs, and what the same display did on the other reading of this mixed meter. Count affected records out of 12 mixed records and affected layouts out of six, including layouts where both readings drew a false definite claim. There is no inference of guessing intent.

A synthetic regression panel partitions eight labeled settings into four disjoint cells of two. The implementation enumerates all 255 nonempty subsets under all three verdicts against a mixed target and two determinate targets, then checks duplicate and missing-answer cases separately. All code runs locally with the Python standard library.
