# Editing a single checkpoint label

Preregistered conditional intervention. From parent 4288df5 take all twelve homogeneous records in the six previous layouts. This fixed-record experiment intentionally reuses the tables that produced five false existential answers. There are no newly sampled circuits or newly elicited label turns. Every cell is a new inference, including each unchanged historical request. No paid API use.

For each row pair generate a faithful checkpoint and a conflicting checkpoint that flips exactly one value, preserving all other characters of the original role-tagged conversation. For the five genuine transcription errors the conflict text is exactly the earlier model's response. For the remaining all-negative control edit the second ID. For the six all-positive cases alternate the edited position by layout. In these seven cases conflict is investigator-supplied. Issue both quantifier questions against each map in isolated requests, with parent model, low reasoning, seed, grammar, context and budget unchanged. Record order is randomized at the level of each matched pair of calls. Within each of the four truth-by-question strata, three of six pairs start faithful and three start conflicting. The two siblings share a seed, have no exposure to one another's outputs and run locally on the same server. The frozen schedule specifies 48 requests. If a call fails, keep its receipt and mark its answer missing. No substitution, retries of dispatched calls or optional stopping.

Primary endpoint: among all five original false-existence cases, count records on which the fresh replay with the genuine mistaken report answers yes AND a fresh call with the one-character repair answers no. Retain all five in the denominator. Report the six all-negative existential contrasts, the six all-positive universal contrasts, and all 12 invariant question pairs. Record control direction, reversals, unchanged outputs, missing answers, the full layout-by-layout ledger and fidelity to the historical answers on all 24 unedited request replays.

H1: displayed evidence dominates. Faithful and conflict answers both match the circuit label. H2: checkpoint content controls the reduction. Flipping a sign changes existence only on all-negative records, universality only on all-positive records. On both strata the other question should be invariant. H3: one or both directions have weak or heterogeneous effects, or fixed-input replays disagree. The all-positive conflicts test whether false negative claims can be induced as well as false positives. Accurate answers on invariant questions alone cannot distinguish evidence use and checkpoint use. Report exact counts without population inference. Isolate the effect of editing textual conversation history within this interface; a concordant pattern cannot establish hidden model reasoning, failure prevalence on new circuits, or a mathematical result about the source Lean proof.
